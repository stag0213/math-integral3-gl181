# 立体 $x^2+y^2\le 1,\ 0\le z\le x^2$ の3D可視化

円柱 $x^2+y^2\le 1$ の内部で、底面 $z=0$ と放物柱面 $z=x^2$ に挟まれた立体

$$
D=\{(x,y,z)\mid x^2+y^2\le 1,\ 0\le z\le x^2\}
$$

を、ブラウザ上でインタラクティブに3D表示する Web アプリケーションです。
断面を動かしながら断面積とその積分値を確かめ、体積 $V=\dfrac{\pi}{4}$ が得られる様子を観察できます。

## 特長

- **3D表示**：Three.js で立体を描画し、マウスで回転・平行移動・拡大縮小できます。
- **面ごとの表示切り替え**：上面 $z=x^2$、側面 $x^2+y^2=1$、底面 $z=0$ を個別に表示・非表示にできます。
- **補助曲面**：立体を作る円柱面と放物柱面の全体を半透明で重ねて表示できます。
- **断面の観察**：$x$・$y$・$z$ のいずれかを一定にした断面を表示し、スライダーやアニメーションで位置を動かせます。
- **切断表示**：断面より先の部分を切り取り、立体の内部の形を確認できます。
- **断面積グラフ**：断面積 $A$ のグラフと、その積分値（塗りつぶし部分）がその場で更新されます。
- **数式表示**：KaTeX により、根号・分数・積分記号などを正しく組版して表示します。

## 使い方

1. `solid.html` をダウンロードします。
2. Chrome、Edge、Firefox、Safari などのモダンブラウザで開きます（ダブルクリックで開けます）。
3. 画面左のパネルで表示や断面を操作します。

> **注意**：Three.js と KaTeX を CDN から読み込むため、インターネット接続が必要です。

ローカルサーバーで動かしたい場合は、例えば次のように起動します。

```bash
python -m http.server 8000
# ブラウザで http://localhost:8000/solid.html を開く
```

## 操作方法

### マウス操作

| 操作 | 動作 |
| --- | --- |
| 左ドラッグ | 回転 |
| 右ドラッグ | 平行移動 |
| ホイール | 拡大・縮小 |

### パネルの項目

| 項目 | 内容 |
| --- | --- |
| 上面・側面・底面 | 各面の表示・非表示 |
| 補助曲面 | 円柱面と放物柱面の全体を半透明で表示 |
| ワイヤーフレーム | 立体を線画で表示 |
| 座標軸・グリッド | 座標軸と $xy$ 平面のグリッドの表示 |
| 不透明度 | 立体の透明度を調整 |

| 断面の向き | $x$・$y$・$z$ のどれを一定にするかを選択 |
| 位置スライダー | 断面の位置を変更 |
| 断面より先を切り取る | 断面の手前側だけを残して表示 |
| アニメーション | 断面を自動で往復させる |

立体の色は高さ $z$ を表します（青：$z=0$ → 赤：$z=1$）。

## 数学的な背景

### 立体の形

上面 $z=x^2$ は $y$ 軸（$x=0$）に沿って底面に接し、$x=\pm 1$ の側では高さ $1$ まで持ち上がります。
そのため、$yz$ 平面に関して左右対称な、蝶のような形になります。

### 体積

極座標 $x=r\cos\theta,\ y=r\sin\theta$ を使うと、

$$
V=\int_0^{2\pi}\!\!\int_0^1 r^2\cos^2\theta\cdot r\,dr\,d\theta
=\frac{1}{4}\int_0^{2\pi}\cos^2\theta\,d\theta
=\frac{1}{4}\cdot\pi=\frac{\pi}{4}\approx 0.7854
$$

となります。

### 断面積

| 切り方 | 断面の形 | 断面積 | 範囲 |
| --- | --- | --- | --- |
| $x=a$ | 長方形（幅 $2\sqrt{1-a^2}$、高さ $a^2$） | $A(x)=2x^2\sqrt{1-x^2}$ | $-1\le x\le 1$ |
| $y=b$ | 放物線 $z=x^2$ の下の領域 | $A(y)=\dfrac{2}{3}(1-y^2)^{3/2}$ | $-1\le y\le 1$ |
| $z=c$ | 円から帯 $\lvert x\rvert<\sqrt{c}$ を除いた2つの弓形 | $A(z)=\pi-2\left(\sqrt{z}\sqrt{1-z}+\arcsin\sqrt{z}\right)$ | $0\le z\le 1$ |

どの向きの断面積を積分しても、

$$
\int_{-1}^{1}A(x)\,dx=\int_{-1}^{1}A(y)\,dy=\int_{0}^{1}A(z)\,dz=\frac{\pi}{4}
$$

となります。アプリでは、断面の位置までの積分値をシンプソン法で数値計算して表示しています。

## 技術構成

| ライブラリ | バージョン | 用途 |
| --- | --- | --- |
